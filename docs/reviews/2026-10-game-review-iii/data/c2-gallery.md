# Screen gallery (data)

Area 2 of the third review. Written by the repaired `npm run review:gallery` (`tools/review/gallery.mjs`) at commit `b1f2114`, against the production build (`vite preview`, port 4102). PNGs are working files, not committed. "Words / controls" count the top layer (the last dialog open, else the page); `*` = the layer scrolls. A control is a visible, enabled button, link, field, tab or slider.

**Saves** (the shared bank, built from `b1f2114`): `founding` (week one), `summer1` (Guided, year 1 summer held; made here), `year-3-first-hall` (Y4), `guided-y5-clear` (Y6), `year-8-balanced` (Y9), `crisis` (Y16), `year-25-rich` (Y26), `summer30` (Completionist, Y30 summer held; made here), `year-40-done` (Y41), `specialization` (Y23, the choice held), `training` (Y38), `summer` (Y6 summer held). Every harness save opens with Guided's briefing over the map (area 7's I7-5), so "map" counts the map *with* the drawer; the map alone, counted with Objectives on Brief, is in the area file.

**Known artifacts.** The harness names every college "Test College/University". Harness colleges never appoint a Provost, so every save past Y5 sits in chapter 5 or 13 (I7-5).
