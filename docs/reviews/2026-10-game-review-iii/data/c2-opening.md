# The opening, counted (data)

Area 2 of the third review, commit `b1f2114`, production build. A scripted newcomer (`c2/tools/opening.mjs`, kept in the review's scratch directory) founds a college at 1440×900, follows the walkthrough, does what each chapter's lead objective asks (develop courses, site the buildings the build menu rings, open the tabs asked for), presses each briefing's first *Show me*, plays at 2× and answers every stop with its advance button, to the start of year 3. Each row counts the words in the coach card, the letter or page, the drawer, the ticker strip and the whole page at that moment. A second run (`open-passive`) that only answered stops reached the same first summer with no seats built.
