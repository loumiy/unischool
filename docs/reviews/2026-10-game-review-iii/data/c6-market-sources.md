# Area 6 — the market sources, 21 October 2026

*Every outside figure in [`../6-marketability.md`](../6-marketability.md), with how it was read. "Fetched" means the page itself was read through the review's web-fetch tool. That tool returns a summarizing model's reading of the page, so figures are as reliable as a careful paraphrase: quotes marked as quotes are verbatim, and anything going into a pitch deck should still be checked by hand. "Extract" means only a search engine's snippet was seen. Direct `curl` from the container was refused by the proxy (itch.io's image CDN and Vimeo, 403), so no image, video or file was downloaded.*
