# Plan 111 PR B: before and after

The rest of the chapters (*Campus life* on), the board's letters, the
milestone letters after the Founding tier, the decision events and
letters in `eventData.ts` that PR A did not touch, the specialization
words, the university charter's log line, and a few campaign and demand
lines. 188 strings in all. `{…}` stands for a template placeholder.

Facts corrected along the way:

- *Campus life*: a matter left unanswered decided itself "after four
  weeks". Each matter has its own time limit (1 to 6 weeks in the
  catalogue), so the briefing now says it decides itself "when its time
  runs out".
- *The laboratories*: the letter said the board asks you to see a project
  through in every lab, in the same breath as the Research Park. That
  condition on the park was dropped (projectData.ts); the park opens with
  the research specialization alone. The letter now says only to start a
  project in each lab.
- *Research*: the optional objective "Answer the board on the university
  charter" is met when the charter is offered, so it now reads "Be offered
  a university charter".
- *The director wants a coach hired*: "Leave it to the open market" said
  the post stays empty "until a head coach is hired", whatever the post.
  It now says "until you hire someone".
- The fought recruiting scandal's log line gave the ban's end as a bare
  number ("through 7"). It now says "through Year 7".
