# Plan 111 PR D, part two: help paragraphs and tooltips

Every player-facing string this PR changed, before and after. `{…}` stands for a template placeholder. Where one string is built from several pieces (JSX text around values), the pieces are joined with ` … `.

Text only: no rule, number, id or key changed. One line was wrong about the game and now matches the code:

- History › The record, the Enrolled chart's note said "Each summer's entering class". The chart plots everyone enrolled (`captureYearSnapshot` records `totalEnrolled`), so it now says "Students enrolled each summer."

Unexplained terms replaced: the training picks "lapse" now "expire"; an office's slot "dark" now "can't be used"; the program tile's "dark" chip keeps its word but its hover now says what it means.

Left alone on purpose: `ConfirmButton` `label`, `armedLabel` and `warning` props (the confirmation-buttons PR owns them); the specialization cards' `fills` clauses (they slot into a sentence built elsewhere, and tests pin them); `dragLine` ("Housing is the drag: …", pinned exactly by tests); the "From … to the President" address lines on inbox letters (they name the seat, as a letter's address); short labels that already read well.
